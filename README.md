A little project I did for halloween 2024. Basically, it is an animatronic head based of the caracter freddy from fnaf.

Here is the link to the 3d printed parts:

[Link to THingiverse](https://www.thingiverse.com/thing:6699689)

The "C++" code in this repository is for an arduino uno. It utilizes two servo motors and 3 buttons. 
I/O:
2 = servo1 for eye lids down
3 = servo2 for eyes look left
4 = servo2 for eyes look right

8 = servo2
9 = servo1
